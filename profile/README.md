# Virtual Edge Tech

**Virtual Edge Tech** builds Microsoft 365 business applications and SharePoint solutions using Power Apps, Power Automate, SharePoint Online, and PowerShell.

Our open-source applications are designed to run in your own Microsoft 365 tenant. Experienced administrators and consultants can install and configure them using the documentation provided with each project.

Additional walkthroughs, screenshots, FAQs, and optional installation services are available at [virtualedgetech.com](https://virtualedgetech.com/).

## Open-Source Applications

### Expense Report

Submit, approve, and manage employee expense reports using Power Apps, Power Automate, and SharePoint.

Repository: [expense-report](https://github.com/virtualedgetech/expense-report)

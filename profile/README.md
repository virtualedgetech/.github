# Virtual Edge Tech

Virtual Edge Tech builds practical Microsoft 365 solutions using SharePoint Online, Power Apps, Power Automate, and PowerShell.

We publish free, open-source applications that organizations can run in their own Microsoft 365 tenants. Each application is designed for self-installation by experienced Microsoft 365 administrators and consultants, with optional fixed-price installation and configuration services available from [Virtual Edge Tech](https://virtualedgetech.com/).

[Website](https://virtualedgetech.com/) · [Applications](https://virtualedgetech.com/applications) · [Services](https://virtualedgetech.com/services) · [Resources](https://virtualedgetech.com/resources)

## Applications in Development

The following applications are under active development. Features, requirements, documentation, and release plans may change before publication.

### Expense Report

A Microsoft 365 application for submitting, reviewing, approving, and tracking employee expense reports and supporting receipts.

**Status:** In development

### Inspections

A mobile-friendly application for recording inspections, documenting findings and photos, assigning corrective actions, and tracking work through resolution.

**Status:** In development

### Microsoft 365 Portal Administration

An administrative application for managing common portal operations such as users, access, organizational groups, and SharePoint workspaces from a consistent interface.

**Status:** In development

### Time Off

An application for submitting and approving time-off requests, viewing request status and history, and supporting an organization's leave-management process.

**Status:** In development

### Issue Reporting

A centralized application for reporting issues, assigning responsibility, tracking status and activity, and maintaining a history through resolution.

**Status:** In development

Application repositories and installation documentation will be linked here as they become available. Visit the [application catalog](https://virtualedgetech.com/applications/catalog) for current availability and additional information.
